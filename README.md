# AI Face Detection Web App

An interactive web application built with **React.js**, **Node.js/Express**, and **PostgreSQL** that detects faces in images using the **Face++ API**. Users can register, sign in, and level up as they successfully detect faces, progressing from *Beginner* to *Master*.

---

## 🚀 Features

- 🔐 **Authentication**: Register and sign in with secure password hashing (`bcrypt`).
- 🖼️ **Face Detection**: Paste an image URL and detect faces via the Face++ API.
- 📈 **Level Progression**: Each successful detection upgrades the user’s level (Beginner → Intermediate → Advanced → Expert → Master).
- 🎨 **UI/UX Enhancements**: Neon/glassmorphism design, responsive layout, animated interactions.
- 🌐 **Deployment Ready**: Backend hosted on Render with PostgreSQL integration.

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- Tachyons (for styling)
- Custom CSS (glassmorphism/neon effects)

**Backend**
- Node.js + Express
- PostgreSQL (via Knex.js)
- bcrypt (password hashing)
- Face++ API integration

**Deployment**
- Render (backend + database)
- GitHub Pages / Vercel (frontend)
